# Kalman Filter Simulation (Week 1 – Basics)

This project explores **Kalman Filters (KF)** as part of my robotics software engineering prep.  
Goal: build step by step implementations in **Python and C++**, moving from 1D KF to EKF and PF.

## 📂 Structure

cpp/      → C++ Eigen-based KF implementations  
python/   → Python prototyping with NumPy/Matplotlib  
notes/    → math derivations and explanations  
data/     → plots and CSV results  




## 🗓 Roadmap (Week 1)
- Day 1: Repo skeleton + state-space notes  
- Day 2: 1D KF in Python  
- Day 3: 1D KF in C++ (Eigen)  
- Day 4: 2D KF (pos/vel)  
- Day 5: EKF (bicycle model)  
- Day 6–7: Particle Filter + comparisons  

## 🔧 Tools
- C++17, Eigen3, CMake  
- Python 3, numpy, matplotlib  
- Git, Docker (optional)
